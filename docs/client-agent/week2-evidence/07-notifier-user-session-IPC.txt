--- 4. Notification Dispatch Trace upon BLOCKED Event ---
1. USBGuard detects unauthorized USB Mass Storage insertion.
2. UsbGuardEventListener resolves active UID = 1000.
3. UnixSocketNotificationPublisher connects to /run/usbshield-notifier/1000.sock.
4. Payload sent to helper:
   {
     "vendorId": "0951",
     "productId": "1666",
     "deviceName": "Kingston DataTraveler 3.0",
     "reason": "Unauthorized USB Mass Storage Device Blocked by Policy"
   }
5. DesktopNotificationClient receives payload and executes /usr/bin/notify-send via argv in student01's GUI session.
6. Desktop notification popup displays on GNOME/Wayland desktop.
