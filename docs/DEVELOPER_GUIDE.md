## Truy vết một thay đổi

**Workspace và enrollment.** [AdminAuthController](../admin-server/src/main/java/com/group/usbshield/server/auth/AdminAuthController.java) tạo principal từ tài khoản và workspace đã xác minh. Gắn điều kiện workspace tại truy vấn trước phân trang, join hoặc aggregate, kể cả khi dùng JDBC. [EnrollmentService](../admin-server/src/main/java/com/group/usbshield/server/agentapi/EnrollmentService.java) khóa endpoint trước ticket và commit credential/receipt cùng lúc. [Migration V3](../admin-server/src/main/resources/db/migration/V3__workspace_boundary.sql) dùng khóa ngoại ghép cho dữ liệu liên quan. Khi thêm đường đọc hoặc ghi, kiểm thử hai workspace có cùng HASH và thử ID của workspace bên kia.

**Policy.** Bắt đầu ở thao tác Allow/Revoke trong [DesktopController](../admin-desktop/src/main/java/com/group/usbshield/desktop/DesktopController.java). `CentralClient` gọi [AdminEndpointWhitelistController](../admin-server/src/main/java/com/group/usbshield/server/policy/AdminEndpointWhitelistController.java) và [EndpointPolicyService](../admin-server/src/main/java/com/group/usbshield/server/policy/EndpointPolicyService.java). Service khóa endpoint và quản lý desired revision. Bên Agent, [HeartbeatCoordinator](../client-agent/src/main/java/com/group/usbshield/agent/sync/HeartbeatCoordinator.java) gọi [PolicySyncService](../client-agent/src/main/java/com/group/usbshield/agent/sync/PolicySyncService.java). [UsbGuardPolicySynchronizer](../client-agent/src/main/java/com/group/usbshield/agent/usbguard/UsbGuardPolicySynchronizer.java) reconcile, kiểm tra rules và rollback theo khả năng adapter. Khi mở rộng, test duplicate, invalid snapshot, reconcile/persist failure và ACK retry.

**USB event.** Theo [UsbGuardEventListener](../client-agent/src/main/java/com/group/usbshield/agent/usbguard/UsbGuardEventListener.java) tìm watch/recovery, active session và quyết định. [EventSenderService](../client-agent/src/main/java/com/group/usbshield/agent/event/EventSenderService.java) đóng payload vào [OutboxSpoolService](../client-agent/src/main/java/com/group/usbshield/agent/outbox/OutboxSpoolService.java). [AgentEventController](../admin-server/src/main/java/com/group/usbshield/server/agentapi/AgentEventController.java) xác thực association và xử lý idempotency. Nếu thêm trường sự kiện đã được duyệt, cập nhật payload/DTO ở cả hai phía, migration nếu cần và API read/mapping. Kiểm tra giữ nguyên `eventId` khi retry và semantics `UNKNOWN` khi thiếu session.

## Build và test từ repo root

- Agent unit: `mvn -f client-agent/pom.xml test`. Gateway/notification test double hữu ích cho regression. Kiểm tra USBGuard thật và Unix IPC cần Ubuntu.
- Backend fixture unit: `mvn -f admin-server/pom.xml "-Dtest=AgentEventContractTest" test`.
- Backend integration: chuẩn bị database `usbshield_test` và role test `usbshield_test` có quyền tạo schema. Tạo `.env` local từ [.env.example](../.env.example). Trong một phiên PowerShell dành riêng cho test, chạy `& ./scripts/with-env.ps1 -RequireTestDb -Command { mvn -f admin-server/pom.xml test }`. Helper đặt env process và kết thúc phiên với exit code của test.
- Desktop: `mvn -f admin-desktop/pom.xml package`. Test contract dùng TLS loopback và CA synthetic. Smoke FXML chạy với JavaFX toolkit trên Windows. [Windows verifier](../packaging/tests/verify-windows.ps1)
- Tích hợp Windows: chạy `./packaging/tests/verify-windows.ps1 -AdminOnly` với PostgreSQL test trên loopback. Verifier giải nén ZIP, khởi động Nginx và Central trên cổng tạm, chạy native readiness và Desktop client trên schema synthetic riêng. Truyền `-NginxPath`, `-OpenSslPath` hoặc `-PsqlPath` nếu tool không ở đường dẫn mặc định. Phép thử dùng hai listener loopback. Gate mất Internet trên LAN thật dùng quy trình [IT](IT_SETUP_GUIDE.md).
- Binaries: [IT setup](IT_SETUP_GUIDE.md) mô tả JAR, .deb, cấu hình và chẩn đoán. Không dùng DB vận hành cho test và không dùng thiết bị chứa dữ liệu thật để nghiệm thu thao tác có thể gián đoạn I/O.

Giữ dependency direction theo use case. Tách thêm port/module khi nó cô lập một boundary thực tế. Mọi thay đổi hành vi cập nhật [API](API.md), [kiến trúc](ARCHITECTURE.md) và guide liên quan trong cùng slice. [Blueprint](../BLUEPRINT.md) mô tả hướng refactor và các gate sau.
